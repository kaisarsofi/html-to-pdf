Images and Figures

An image is atomic: it is never sliced across a page boundary. Below, the image bytes are fetched and embedded once each — a second use of the same source hits the writer's embed cache rather than re-encoding it.

Second format

The writer picks embedPng or embedJpg from the source's extension and response content type, so both formats work without the caller declaring anything.

Repeat use

The same PNG again, to exercise the cache — the output PDF still contains one copy of it.
